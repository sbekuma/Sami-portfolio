Sami Bekuma - Machine Learning Engineer Portfolio

A modern, high-performance portfolio website built to showcase machine learning projects, technical skills, and professional experience.

🚀 Tech Stack

Framework: React + Vite

Styling: Tailwind CSS

Icons: Lucide React

Deployment: Optimized for Netlify / Vercel

Form Handling: FormSubmit (No backend required)

🛠️ Installation & Setup

Clone the repository

git clone [https://github.com/yourusername/portfolio.git](https://github.com/yourusername/portfolio.git)
cd portfolio


Install dependencies

npm install


Run locally

npm run dev


The site will be available at http://localhost:5173.

📦 Building for Production

To create a production-ready build:

npm run build


This will generate a dist folder containing the optimized static files.

📁 Project Structure

src/App.jsx - Main application logic and layout.

public/ - Static assets (images, PDFs).

Sami Bekuma ML Engineer.pdf - Resume file.

comcast.png - Company logo.

care-connect.png - Project screenshot.

rag-architecture.png - Architecture diagram.

🎨 Customization

Theme: The site includes a Dark/Light mode toggle. Default colors can be adjusted in the t object within portfolio.jsx.

Contact Form: The form is configured to use FormSubmit. Update the email address in handleContactSubmit to your own.
